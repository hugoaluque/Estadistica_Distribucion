Distribución Normal y Distribución Muestral: Fundamentos, Puntaje Z y Aplicaciones

Documento técnico-práctico sobre el modelo gaussiano, estandarización mediante puntaje Z, Teorema del Límite Central (TLC), laboratorio gráfico interactivo y resolución computacional en Python orientada a calidad del aire, tecnología de la madera, hidrobiología y edafología.

Sección 01

Marco Teórico y Ecuaciones Fundamentales

1.1 Características de la Distribución Normal

Una variable aleatoria continua X sigue una distribución normal con media poblacional μ y varianza σ2, denotada como X ∼ N(μ, σ2), cuando su Función de Densidad de Probabilidad (FDP) está dada por:

f(x) = 1 σ√2π · e−½[(x − μ) / σ]²

Simetría y Unimodalidad

La curva tiene forma de campana simétrica respecto a μ. En el centro coinciden exactamente la media, la mediana y la moda (μ = Me = Mo).

Asintoticidad y Área Unitaria

Las colas se extienden indefinidamente hacia −∞ y +∞ sin tocar el eje horizontal (f(x) > 0). El área total bajo la curva es exactamente igual a 1 (100%).

Puntos de Inflexión

La curvatura cambia de concavidad exactamente a una desviación estándar de la media: en x = μ − σ y x = μ + σ.

Regla Empírica (68% – 95% – 99.7%)

El 68.27% de los datos cae en μ ± 1σ, el 95.45% en μ ± 2σ y el 99.73% dentro de μ ± 3σ.

1.2 Estandarización y Puntaje Z

La estandarización convierte cualquier variable X ∼ N(μ, σ2) en la Distribución Normal Estándar Z ∼ N(0, 1), midiendo cuántas desviaciones estándar se aleja un valor x respecto a μ:

Z = x − μ σ
  • Z > 0: El valor observado está por encima de la media poblacional.
  • Z < 0: El valor observado está por debajo de la media poblacional.
  • Z = 0: El valor coincide exactamente con el promedio (x = μ).

1.3 Distribución Muestral y Teorema del Límite Central

Al extraer muestras aleatorias de tamaño n, la media muestral X presenta menor dispersión alrededor de μ. Según el Teorema del Límite Central (TLC), para n ≥ 30 o poblaciones normales, X ∼ N(μ, σ2/n):

σx = σ √n
Z = X − μ σ / √n

El error estándar (σx) disminuye inversamente con la raíz cuadrada del tamaño de muestra n.

Ejercicio 01 • Calidad del Aire

Cumplimiento del ECA de Material Particulado (PM10)

En una estación periurbana con vías sin asfaltar, la concentración diaria de PM10 sigue una distribución normal con μ = 88 μg/m3 y σ = 18 μg/m3. El Estándar de Calidad Ambiental (ECA) diario es 100 μg/m3.

Evalúe la probabilidad de excedencia (> 100 μg/m3) en: (A) un día aislado (n = 1) y (B) el promedio de una campaña de n = 9 días.

Parámetro Esc. A / Esc. B
Media (μ) 88 μg/m3
Desv. estándar (σ) 18 μg/m3
Tamaño muestra (n) 1  /  9
Valor crítico (x o x) 100 μg/m3
Tipo de probabilidad P(X > x) Derecha
Ver solución paso a paso e interpretación ▾

Escenario A (n = 1): SE = 18.00 μg/m3; Z = (100 − 88)/18 = +0.6667 → P(X > 100) = 25.25%.

Escenario B (n = 9): SE = 18/√9 = 6.00 μg/m3; Z = (100 − 88)/6 = +2.0000 → P(X > 100) = 2.28%.

Interpretación: Aunque 1 de cada 4 días individuales excede el ECA por ráfagas de viento y tráfico, promediar 9 días estabiliza la dispersión y reduce la probabilidad de excedencia media al 2.28%.

Ejercicio 02 • Tecnología de la Madera

Densidad Básica en Rodal Cosechable de Pino

La densidad básica de la madera en un rodal cosechable presenta μ = 0.46 g/cm3 y σ = 0.05 g/cm3. Se extrae una muestra aleatoria de n = 25 probetas para control de calidad estructural.

Calcule la probabilidad de que la densidad media muestral (X) sea inferior o igual al umbral mínimo estructural de 0.44 g/cm3.

Parámetro Valor a ingresar
Media (μ) 0.46 g/cm3
Desv. estándar (σ) 0.05 g/cm3
Tamaño muestra (n) 25
Valor crítico (x) 0.44 g/cm3
Tipo de probabilidad P(X ≤ x) Izquierda
Ver solución paso a paso e interpretación ▾

1. Error estándar: SE = 0.05 / √25 = 0.05 / 5 = 0.0100 g/cm3.

2. Puntaje Z: Z = (0.44 − 0.46) / 0.01 = −2.0000.

3. Probabilidad: P(X ≤ 0.44) = 2.28% (0.0228).

Significado del Z negativo: Indica que el umbral de 0.44 g/cm3 se ubica exactamente 2 errores estándar por debajo de la media del rodal, haciendo muy improbable rechazar el lote por baja densidad.

Ejercicio 03 • Calidad del Agua

Oxígeno Disuelto (OD) en Río Altoandino

En una subcuenca altoandina, el Oxígeno Disuelto (OD) registra una media histórica de μ = 6.8 mg/L y desviación estándar σ = 1.2 mg/L. El estándar mínimo para conservación acuática es 6.2 mg/L.

Determine la probabilidad de que el promedio de una campaña de n = 16 puntos caiga por debajo de 6.2 mg/L y compárelo con una muestra puntual (n = 1).

Parámetro Muestra / Puntual
Media (μ) 6.8 mg/L
Desv. estándar (σ) 1.2 mg/L
Tamaño muestra (n) 16  /  1
Valor crítico (x o x) 6.2 mg/L
Tipo de probabilidad P(X ≤ x) Izquierda
Ver solución paso a paso e interpretación ▾

Campaña (n = 16): SE = 1.2 / √16 = 0.30 mg/L; Z = (6.2 − 6.8)/0.30 = −2.0000 → P(X ≤ 6.2) = 2.28%.

Medición puntual (n = 1): SE = 1.20 mg/L; Z = (6.2 − 6.8)/1.20 = −0.5000 → P(X ≤ 6.2) = 30.85%.

Interpretación: Una medición puntual tiene casi 31% de probabilidad de caer bajo 6.2 mg/L por variación horaria natural, pero si el promedio de 16 estaciones cae bajo 6.2 mg/L, constituye una alerta ambiental significativa.

Caso Python 01 Calidad del Aire: Excedencia Normativa ECA y Percentil 95 de PM10
X ∼ N(78, 16²)
Problemática Ambiental: En una estación de monitoreo atmosférico urbano-industrial, la concentración diaria de PM10 sigue una distribución normal con μ = 78 μg/m3 y σ = 16 μg/m3. Se requiere calcular: (a) la probabilidad diaria de exceder el ECA de 100 μg/m3 y (b) el percentil 95 (P95) para activar protocolos de alerta temprana.
Script en Python (SciPy + Matplotlib) 
import numpy as np
import scipy.stats as stats
import matplotlib.pyplot as plt

# 1. Parámetros poblacionales de PM10 (µg/m³)
mu = 78.0
sigma = 16.0
eca_limite = 100.0

# 2. Puntaje Z y probabilidad de excedencia P(X > 100)
z_eca = (eca_limite - mu) / sigma
prob_excedencia = stats.norm.sf(eca_limite, loc=mu, scale=sigma)  # 1 - CDF

# 3. Percentil 95 (cálculo inverso)
p95_conc = stats.norm.ppf(0.95, loc=mu, scale=sigma)
z_p95 = stats.norm.ppf(0.95)

print(f"Puntaje Z para ECA (100 µg/m³) : {z_eca:.4f}")
print(f"Probabilidad P(X > 100)        : {prob_excedencia:.6f} ({prob_excedencia*100:.2f}%)")
print(f"Días esperados al año > ECA    : {prob_excedencia * 365:.1f} días/año")
print(f"Concentración Percentil 95     : {p95_conc:.2f} µg/m³ (Z = {z_p95:.4f})")
Salida de consola esperada:

Días esperados al año > ECA    : 30.9 días/año
Concentración Percentil 95     : 104.32 μg/m³ (Z = 1.6449)
Caso Python 02 Dasometría Forestal: Estructura Diamétrica (DAP) en Bosque de Polylepis
X ∼ N(18.5, 4.2²)
Problemática Forestal: En un inventario forestal de un rodal altoandino de queñua (Polylepis spp.), el Diámetro a la Altura del Pecho (DAP) se distribuye normalmente con μ = 18.5 cm y σ = 4.2 cm. Se desea estimar: (a) la proporción de fustales intermedios (15 cm ≤ DAP ≤ 25 cm) y (b) el porcentaje de regeneración avanzada (DAP < 12 cm).
Script en Python (Probabilidad por Intervalos y Colas) 
import scipy.stats as stats

# 1. Parámetros dasométricos del rodal (cm)
mu_dap = 18.5
sigma_dap = 4.2

# 2. Intervalo fustal P(15 <= DAP <= 25)
z1 = (15.0 - mu_dap) / sigma_dap
z2 = (25.0 - mu_dap) / sigma_dap
prob_fustal = stats.norm.cdf(25.0, mu_dap, sigma_dap) - stats.norm.cdf(15.0, mu_dap, sigma_dap)

# 3. Regeneración avanzada P(DAP < 12)
z3 = (12.0 - mu_dap) / sigma_dap
prob_regen = stats.norm.cdf(12.0, mu_dap, sigma_dap)

print(f"Puntajes Z intervalo [15, 25] : Z1 = {z1:.4f}, Z2 = {z2:.4f}")
print(f"Proporción fustal [15-25 cm]  : {prob_fustal:.6f} ({prob_fustal*100:.2f}%)")
print(f"Regeneración avanzada (<12 cm): {prob_regen:.6f} ({prob_regen*100:.2f}%, Z3 = {z3:.4f})")

Caso Python 03 Hidrobiología y TLC: Simulación Monte Carlo de Oxígeno Disuelto (OD)
n = 1 vs. n = 25
Problemática Hidrobiológica: En un tributario altoandino, el Oxígeno Disuelto (OD) presenta μ = 6.2 mg/L y σ = 1.1 mg/L. El umbral crítico para fauna íctica es 5.5 mg/L. Mediante simulación Monte Carlo de 100,000 campañas de n = 25 estaciones, verificamos el Teorema del Límite Central frente a una medición puntual (n = 1).
Script en Python (Distribución Muestral y Simulación Monte Carlo) 
import numpy as np
import scipy.stats as stats

mu_od, sigma_od, umbral, n = 6.2, 1.1, 5.5, 25

# Medición puntual (n = 1) vs Distribución muestral (n = 25)
prob_puntual = stats.norm.cdf(umbral, loc=mu_od, scale=sigma_od)
error_estandar = sigma_od / np.sqrt(n)
prob_muestral = stats.norm.cdf(umbral, loc=mu_od, scale=error_estandar)

# Simulación Monte Carlo (100,000 campañas de 25 estaciones)
rng = np.random.default_rng(seed=42)
medias_campana = rng.normal(loc=mu_od, scale=sigma_od, size=(100_000, n)).mean(axis=1)
prob_mc = np.mean(medias_campana < umbral)

print(f"Puntual (n=1)  -> P(X < 5.5)  : {prob_puntual*100:.2f}%")
print(f"Error estándar (n=25)         : {error_estandar:.4f} mg/L")
print(f"Muestral (n=25)-> P(X̄ < 5.5)  : {prob_muestral*100:.4f}%")
print(f"Simulación Monte Carlo TLC    : {prob_mc*100:.4f}%")
Salida de consola esperada:
Puntual (n=1)  -> P(X < 5.5)  : 26.23%
Error estándar (n=25)         : 0.2200 mg/L
Muestral (n=25)-> P(X̄ < 5.5)  : 0.0732%
Simulación Monte Carlo TLC    : 0.0740%
Caso Python 04 Edafología de Bofedales: Límites de Control para Carbono Orgánico del Suelo (COS)
X̄ ∼ N(145, (28/√16)²)
Problemática Edafológica y MRV de Carbono: En bofedales conservados, el almacenamiento de Carbono Orgánico del Suelo (COS) presenta μ = 145 t C/ha y σ = 28 t C/ha. En parcelas de n = 16 submuestras, se evalúa el riesgo de alerta por degradación (< 132 t C/ha) y se construyen los límites de control de ±2 errores estándar.
Script en Python (Auditoría de Inventarios de Carbono) 
import numpy as np
import scipy.stats as stats

mu_cos, sigma_cos, n_sub, alerta = 145.0, 28.0, 16, 132.0

se_cos = sigma_cos / np.sqrt(n_sub)
z_alerta = (alerta - mu_cos) / se_cos
prob_alerta = stats.norm.cdf(alerta, loc=mu_cos, scale=se_cos)

lci = mu_cos - 2 * se_cos
lcs = mu_cos + 2 * se_cos

print(f"Error estándar (n=16)          : {se_cos:.4f} t C/ha")
print(f"Puntaje Z para X̄ = 132 t C/ha  : {z_alerta:.4f}")
print(f"Probabilidad P(X̄ < 132)        : {prob_alerta*100:.2f}%")
print(f"Límites Control (±2 SE)        : [{lci:.2f}, {lcs:.2f}] t C/ha")
